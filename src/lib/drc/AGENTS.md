# DRC module rules
- DRC scoring: per rule `points + perIssue × extra occurrences`, capped by `cap`; rules flagged `critical` cap the total score at `rules.criticalScoreCap` and force "respins" — all values live in `drc_settings`, student explanations in `src/lib/drc/catalog.ts`.
- Teacher-defined DRC rules live in `settings.customRules` (generic check types in `CHECK_TYPES`, evaluated by `evalCustomRule` in `engine.ts`) and are scored like built-in penalties; their student explanations travel in `report.customCatalog` — rules can be added without code changes.
- Mask expansion, paste reduction/missing paste, via diameter and FAB content rules were calibrated on the Seria A 2025 manual review (`docs/calibrare-seria-a-2025.md`, test `calibration.test.ts`); fiducials (mask ≥ 1.8× pad) are excluded — re-run that calibration before changing their thresholds.
- Industrial DFM rules ERR_54–ERR_62 (mask sliver, acid traps, copper islands/necks, thermal relief, tombstoning, NPTH guard, outline validity, dangling traces, drill-on-trace) live in `engine.ts` after the built-in block, before `customRules`; rectangular flashes use exact SAT distances (`rectSegDist`/`rectRectDist`), the rest capsules — keep `gapBetween` as the single distance entry point.
- `DrcReport.nets` is built by `buildNets` (Union-Find over copper capsules + drill holes across TOP/BOTTOM); net names come from Gerber X2 `%TO.N` attributes when present — never recompute connectivity ad hoc elsewhere.
- Golden Suite (`src/lib/gerber/__tests__/goldenSuite.ts`, panel in `/rules`): 12 synthetic in-memory benchmarks validate parser + DRC end-to-end; add a benchmark when adding a rule, keep `maxMs` budgets realistic, and run `bunx vitest run src/lib/gerber/__tests__ src/lib/drc` before changing parser geometry.
